# Phase Specifications

## Overview

This directory contains the detailed specifications for each development phase.
A Phase is a **unit of delivery** that groups related Modules together.

## How to Read a Phase Spec

Each Phase document defines:
1.  **Goal**: What this phase achieves.
2.  **Modules**: The specific components (e.g., `B01`, `F10`) included.
3.  **Acceptance Criteria**: How we know it's done.
4.  **Demo Impact**: What changes in the Demo Shell.
