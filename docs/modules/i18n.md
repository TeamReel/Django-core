# Internationalization (i18n) Module

Locale management and user language preferences for Django Core-App.

## Overview

The `i18n_preferences` module provides internationalization support with user language preferences, locale detection, and translation management using Django's gettext infrastructure.

**App location**: `src/i18n_preferences/`, `src/locale/`  
**Feature spec**: `kitty-specs/004-core-internationalization-base/`, `kitty-specs/012-user-organisation-i18n/`  
**ADR**: [ADR-012: B10 Preference Storage](../architecture/adr/index.md#user-preferences--internationalization)

## Models

### UserPreference

User locale and display preferences.

| Field | Type | Description |
|-------|------|-------------|
| `user` | OneToOneField | Associated user |
| `language` | CharField | ISO language code |
| `timezone` | CharField | Timezone name |
| `date_format` | CharField | Date display format |
| `theme` | CharField | UI theme (light/dark) |

## Usage Examples

### Setting User Language

```python
from i18n_preferences.models import UserPreference

# Get or create preferences
prefs, _ = UserPreference.objects.get_or_create(
    user=user,
    defaults={'language': 'en'}
)

# Update language
prefs.language = 'fr'
prefs.save()
```

### Getting Current Language

```python
from django.utils import translation

def get_user_language(user):
    """Get user's preferred language."""
    try:
        return user.preferences.language
    except UserPreference.DoesNotExist:
        return settings.LANGUAGE_CODE
```

### Locale Middleware

```python
class UserLocaleMiddleware:
    """Activate user's preferred language."""
    
    def __call__(self, request):
        if request.user.is_authenticated:
            try:
                lang = request.user.preferences.language
                translation.activate(lang)
                request.LANGUAGE_CODE = lang
            except UserPreference.DoesNotExist:
                pass
        
        response = self.get_response(request)
        response.set_cookie(
            settings.LANGUAGE_COOKIE_NAME,
            request.LANGUAGE_CODE,
        )
        return response
```

## Timezone Handling

### User Timezone

```python
from django.utils import timezone
import pytz

def get_user_timezone(user):
    """Get user's timezone."""
    try:
        tz_name = user.preferences.timezone
        return pytz.timezone(tz_name)
    except (UserPreference.DoesNotExist, pytz.UnknownTimeZoneError):
        return timezone.get_current_timezone()
```

### Converting Times

```python
from django.utils import timezone

# Activate user's timezone for request
def timezone_middleware(get_response):
    def middleware(request):
        if request.user.is_authenticated:
            try:
                tz = request.user.preferences.timezone
                timezone.activate(tz)
            except UserPreference.DoesNotExist:
                timezone.deactivate()
        return get_response(request)
    return middleware
```

```django
{% endtimezone %}
```

## Locale Hierarchy

Language detection order:

1. User preference (database)
2. Session cookie
3. `Accept-Language` header
4. Default (`settings.LANGUAGE_CODE`)

```python
def get_language(request):
    """Determine language for request."""
    # 1. User preference
    if request.user.is_authenticated:
        try:
            return request.user.preferences.language
        except UserPreference.DoesNotExist:
            pass
    
    # 2. Session
    if LANGUAGE_SESSION_KEY in request.session:
        return request.session[LANGUAGE_SESSION_KEY]
    
    # 3. Accept-Language header
    accept_lang = request.META.get('HTTP_ACCEPT_LANGUAGE')
    if accept_lang:
        return get_supported_language(accept_lang)
    
    # 4. Default
    return settings.LANGUAGE_CODE
```
