# @django-core/auth-ui

> Lightweight React authentication UI package for Django Core

## Overview

`@django-core/auth-ui` provides production-ready React components and hooks for Django authentication workflows. Built on top of `@django-core/design-system` (F01), it offers:

- 🔐 **Complete Auth Flows**: Sign-in, sign-out, password reset with email confirmation
- ♿ **Accessibility First**: WCAG 2.1 AA compliant with comprehensive ARIA support
- 🎨 **Design System Integration**: Seamlessly uses F01 tokens and components
- 🔒 **Security Built-in**: CSRF protection, XSS prevention, secure session management
- 📱 **Responsive**: Mobile-first design that works on all screen sizes
- 🌍 **I18n Ready**: Internationalization support via B04 preferences
- 🧪 **Well Tested**: 300+ tests with 99% coverage

## Quick Start

### Installation

```bash
pnpm add @django-core/auth-ui
```

### Basic Setup

```tsx
import { AuthProvider, SignInPage } from '@django-core/auth-ui';

const authConfig = {
  apiBaseUrl: '/api/v1',
  endpoints: {
    signIn: '/auth/login',
    signOut: '/auth/logout',
    me: '/auth/me',
  },
  routes: {
    login: '/auth/login',
    defaultAfterLogin: '/dashboard',
  },
};

function App() {
  return (
    <AuthProvider config={authConfig}>
      <SignInPage />
    </AuthProvider>
  );
}
```

## Architecture

### Components

Pre-built, accessible UI components for common auth patterns:

- **Pages**: `SignInPage`, `ForgotPasswordPage`, `ResetPasswordPage`
- **Forms**: `SignInForm`, `RequestPasswordResetForm`, `ConfirmPasswordResetForm`
- **Utilities**: `ProtectedRoute`, `AuthGuard`

### Hooks

React hooks for programmatic authentication:

- `useAuth()` - Access current user and auth state
- `useSignIn()` - Sign in with email/password
- `useSignOut()` - Sign out current user
- `useRequestPasswordReset()` - Request password reset email
- `useConfirmPasswordReset()` - Confirm password reset with token
- `useUpdateProfile()` - Update user profile

### Provider

`<AuthProvider>` manages authentication state globally:

- Automatic session management
- Token refresh
- CSRF protection
- Error handling
- Loading states
