# API Contract: POST /auth/password-reset-confirm
*B13 Baseline API Endpoint*

**Feature**: F02 Core Auth Identity UI
**Backend**: B05 Core Accounts & Authentication
**Status**: ✅ **IMPLEMENTED** (tested in `tests/accounts/test_auth_api.py`)

---

## Endpoint Details

- **URL**: `POST /api/v1/auth/password-reset-confirm`
- **Authentication**: None required (uses token from email link)
- **Content-Type**: `application/json`
- **CSRF Protection**: ⚠️ **Required** (include `X-CSRFToken` header)

---

## Purpose

Confirm password reset using token from email link. Sets new password for user account.

**Security**: Token is one-time use and expires after 24 hours. All existing user sessions are invalidated after successful password reset.

---

## Request

### Headers

```http
POST /api/v1/auth/password-reset-confirm HTTP/1.1
Host: example.com
Content-Type: application/json
X-CSRFToken: <csrf_token_from_cookie>
```

### Body Schema

```json
{
  "uidb64": "MTIz",
  "token": "a1b2c3-d4e5f6g7h8i9",
  "new_password": "NewSecurePassword123!"
}
```

**TypeScript Interface**:

```typescript
interface ConfirmPasswordResetRequest {
  uidb64: string;       // Base64-encoded user ID (from email link)
  token: string;        // One-time password reset token (from email link)
  new_password: string; // Must meet password complexity requirements
}
```

**Parameters**:
- `uidb64`: Base64-encoded user ID (e.g., "MTIz" = user ID 123)
- `token`: Cryptographic token generated by Django's `default_token_generator`
- `new_password`: New password (must meet validation rules)

---

## Response

### Success (200 OK)

**Body**:

```json
{
  "message": "Password reset successful. You can now log in with your new password."
}
```

**TypeScript Interface**:

```typescript
interface ConfirmPasswordResetResponse {
  message: string;
}
```

**Side Effects**:
- Sets new password for user (hashed with Django's password hasher)
- **Invalidates ALL existing user sessions** (logs out all devices)
- Token is consumed (cannot be reused)
- User can immediately log in with new password

## Example Usage

### JavaScript (fetch)

```javascript
// Extract CSRF token from cookie
function getCsrfToken() {
  const cookies = document.cookie.split(';');
  const csrfCookie = cookies.find(c => c.trim().startsWith('csrftoken='));
  return csrfCookie ? csrfCookie.split('=')[1] : '';
}

// Confirm password reset
async function confirmPasswordReset(uidb64, token, newPassword) {
  const response = await fetch('/api/v1/auth/password-reset-confirm', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-CSRFToken': getCsrfToken(),
    },
    credentials: 'include',
    body: JSON.stringify({
      uidb64,
      token,
      new_password: newPassword,
    }),
  });

  if (!response.ok) {
    const error = await response.json();
    throw new Error(error.error.message);
  }

  return await response.json();
}

// Usage (extract params from URL)
const urlParams = new URLSearchParams(window.location.search);
const uidb64 = urlParams.get('uidb64');
const token = urlParams.get('token');

try {
  const result = await confirmPasswordReset(uidb64, token, 'NewPassword123!');
  console.log(result.message);
  // Redirect to sign-in page
  window.location.href = '/auth/login?reset=success';
} catch (error) {
  console.error('Password reset failed:', error.message);
  // Display error to user
}
```

### React Component Example

```typescript
import { useState, useEffect } from 'react';
import { useSearchParams, useNavigate } from 'react-router-dom';
import { Button, Input, Alert } from '@django-core/design-system';

function ConfirmPasswordResetPage() {
  const [searchParams] = useSearchParams();
  const navigate = useNavigate();

  const uidb64 = searchParams.get('uidb64');
  const token = searchParams.get('token');

  const [newPassword, setNewPassword] = useState('');
  const [confirmPassword, setConfirmPassword] = useState('');
  const [isLoading, setIsLoading] = useState(false);
  const [error, setError] = useState<ApiError | null>(null);

  // Validate token params exist
  useEffect(() => {
    if (!uidb64 || !token) {
      setError({
        status: 400,
        code: 'invalid_link',
        message: 'Invalid password reset link. Please request a new one.',
      });
    }
  }, [uidb64, token]);

  async function handleSubmit(e: React.FormEvent) {
    e.preventDefault();

    // Client-side validation
    if (newPassword !== confirmPassword) {
      setError({
        status: 400,
        code: 'password_mismatch',
        message: 'Passwords do not match.',
      });
      return;
    }

    setIsLoading(true);
    setError(null);

    try {
      const response = await fetch('/api/v1/auth/password-reset-confirm', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'X-CSRFToken': getCsrfToken(),
        },
        credentials: 'include',
        body: JSON.stringify({
          uidb64,
          token,
          new_password: newPassword,
        }),
      });

      if (!response.ok) {
        const errorData = await response.json();
        throw parseApiError(errorData, response.status);
      }

      // Success - redirect to login
      navigate('/auth/login?reset=success');
    } catch (err) {
      setError(err as ApiError);
    } finally {
      setIsLoading(false);
    }
  }

  if (error?.code === 'invalid_link' || error?.code === 'invalid_token') {
    return (
      <>
        <Alert variant="error">
          {error.message}
        </Alert>
        <Button onClick={() => navigate('/auth/password-reset')}>
          Request New Link
        </Button>
      </>
    );
  }

  return (
    <form onSubmit={handleSubmit}>
      {error && (
        <Alert variant="error">
          {error.message}
          {error.fieldErrors?.new_password?.map((msg, i) => (
            <div key={i}>{msg}</div>
          ))}
        </Alert>
      )}

      <Input
        label="New Password"
        type="password"
        value={newPassword}
        onChange={(e) => setNewPassword(e.target.value)}
        required
        error={error?.fieldErrors?.new_password?.[0]}
      />

      <Input
        label="Confirm Password"
        type="password"
        value={confirmPassword}
        onChange={(e) => setConfirmPassword(e.target.value)}
        required
      />

      <Button type="submit" loading={isLoading} disabled={!uidb64 || !token}>
        Reset Password
      </Button>
    </form>
  );
}
```

### Password Validation (Client-Side)

```typescript
function validatePassword(password: string): string[] {
  const errors: string[] = [];

  if (password.length < 8) {
    errors.push('Password must be at least 8 characters long');
  }
  if (!/[A-Z]/.test(password)) {
    errors.push('Password must contain at least one uppercase letter');
  }
  if (!/[a-z]/.test(password)) {
    errors.push('Password must contain at least one lowercase letter');
  }
  if (!/[0-9]/.test(password)) {
    errors.push('Password must contain at least one number');
  }
  if (!/[!@#$%^&*()_+\-=\[\]{}|;:,.<>?]/.test(password)) {
    errors.push('Password must contain at least one special character');
  }

  return errors;
}
```

## Security Considerations

### Token Security

- **One-time use**: Token is consumed after successful reset
- **24-hour expiry**: Tokens expire automatically
- **Cryptographic signing**: Uses Django's `default_token_generator` (HMAC-based)
- **No database storage**: Token is stateless, validated via signature

### Session Invalidation

⚠️ **Critical Security Feature**: All user sessions are invalidated after password reset.

**Rationale**:
- If attacker gained access to account, password reset logs them out
- Forces re-authentication with new password on all devices
- Prevents session hijacking attacks

**Implementation** (from backend):
```python
# After setting new password
user.save()

# Invalidate all sessions for this user
Session.objects.filter(
    session_data__contains=f'"_auth_user_id": "{user.id}"'
).delete()
```

### Rate Limiting

⚠️ **Recommendation**: Implement rate limiting to prevent token brute-force.

**Suggested limits**:
- 5 attempts per token (after 5 failures, token is invalidated)
- 10 attempts per IP per hour

### Password Validation

**Server-side validation** (enforced by Django):
- Minimum 8 characters
- At least 1 uppercase letter
- At least 1 lowercase letter
- At least 1 number
- At least 1 special character
- Not similar to user attributes (email, name)
- Not a common password

**Client-side validation** (for better UX):
- Same rules as server-side
- Show live feedback as user types
- Password strength meter (optional)
