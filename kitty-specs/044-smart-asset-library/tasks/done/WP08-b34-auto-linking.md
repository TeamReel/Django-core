# WP08: B34 Auto-Linking

## Goal
Automatically create MediaItem entries when B34 Generative Pipelines produces output files (images, videos).

## Context

### Design Documents
- **B34 Spec**: GenerationOutput model stores AI-generated content
- **Integration Point**: Signal on GenerationOutput.save() when output has file reference

### Flow
```
B34 Template → Generation Request → Processing → Generation Output (file)
                                                        ↓
                                              Signal fires
                                                        ↓
                                              MediaItem auto-created
                                                        ↓
                                              Tags + Relations auto-set
```

### Key Integration Points
- **GenerationRequest**: Contains project_id, activity_id (optional), user context
- **GenerationOutput**: Contains file reference (output_file FK to FileAsset)
- **GenerationTemplate**: Contains slug for auto-tagging

## Implementation Details

### T033: Signal Handler
Create signal handler at `src/assets/signals.py`:

```python
from django.db.models.signals import post_save
from django.dispatch import receiver
from django.conf import settings

# Only enable if B34 is installed
if "generative" in settings.INSTALLED_APPS:
    from generative.models import GenerationOutput
    from .models import MediaItem, MediaItemState
    from .services.tags import MediaTagService

    @receiver(post_save, sender=GenerationOutput)
    def auto_create_media_item(sender, instance, created, **kwargs):
        """Auto-create MediaItem when GenerationOutput has a file."""
        if not created:
            return

        # Only process outputs with file attachments
        if not instance.output_file:
            return

        # Skip non-media file types
        mime_type = instance.output_file.mime_type or ""
        if not (mime_type.startswith("image/") or mime_type.startswith("video/")):
            return

        # Get context from GenerationRequest
        request = instance.generation_request

        # Create MediaItem
        media_item = MediaItem.objects.create(
            project=request.project,
            file=instance.output_file,
            title=generate_title(instance),
            description=f"Generated by template: {request.template.name}",
            mime_type=mime_type,
            file_size_bytes=instance.output_file.file_size_bytes or 0,
            state=MediaItemState.PENDING,
            created_by=request.created_by,
            activity=request.activity,  # May be None
            generation_request=request,  # Link back to source
        )

        # Auto-tag based on template
        auto_tag_from_template(media_item, request.template)

        # Trigger metadata extraction
        from .tasks import process_media_item
        process_media_item.delay(str(media_item.id))

        return media_item


def generate_title(output):
    """Generate title for auto-created media item."""
    request = output.generation_request
    template = request.template

    # Use output filename if available
    if output.output_file and output.output_file.filename:
        return output.output_file.filename.rsplit(".", 1)[0]

    # Fall back to template name + timestamp
    timestamp = output.created.strftime("%Y%m%d_%H%M%S")
    return f"{template.slug}_{timestamp}"
```

```python
def get_generation_context(media_item) -> dict:
    """Get full context for an AI-generated media item."""
    if not media_item.generation_request:
        return {}

    request = media_item.generation_request
    template = request.template

    return {
        "generation_request_id": str(request.id),
        "template_id": str(template.id),
        "template_name": template.name,
        "template_slug": template.slug,
        "provider": template.provider,
        "input_variables": request.input_variables,
        "completed_at": request.completed_at.isoformat() if request.completed_at else None,
    }
```

### T035: Auto-Tagging from Template
Add auto-tagging based on template:

```python
def auto_tag_from_template(media_item, template):
    """Auto-add tags based on generation template."""
    from .services.tags import MediaTagService

    tags_to_add = []

    # Add template slug as tag
    tags_to_add.append(f"generated-{template.slug}")

    # Add provider tag
    tags_to_add.append(f"ai-{template.provider}")

    # Add "generated" system tag
    tags_to_add.append("ai-generated")

    # Add category-specific tags based on template slug patterns
    if "lineup" in template.slug.lower():
        tags_to_add.append("lineup")
    if "highlight" in template.slug.lower():
        tags_to_add.append("highlight")
    if "thumbnail" in template.slug.lower():
        tags_to_add.append("thumbnail")
    if "tenue" in template.slug.lower() or "kit" in template.slug.lower():
        tags_to_add.append("kit-design")

    # Apply tags
    MediaTagService.tag_media_item(media_item, tags_to_add)
```

Ensure system tags exist (migration or management command):

```python
# src/assets/management/commands/setup_system_tags.py
from django.core.management.base import BaseCommand
from assets.models import MediaTag
from django.utils.text import slugify

SYSTEM_TAGS = [
    "ai-generated",
    "lineup",
    "highlight",
    "thumbnail",
    "kit-design",
    "match",
    "training",
    "profile",
]

class Command(BaseCommand):
    def handle(self, *args, **options):
        for name in SYSTEM_TAGS:
            MediaTag.objects.get_or_create(
                slug=slugify(name),
                defaults={
                    "name": name.replace("-", " ").title(),
                    "project": None,
                    "is_system": True,
                }
            )
        self.stdout.write(f"Created/verified {len(SYSTEM_TAGS)} system tags")
```
