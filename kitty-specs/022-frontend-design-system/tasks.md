**Constitutional Compliance**: All tasks align with Django Core-App Constitution principles (adapted for frontend context).

## Subtask Format: `[Txxx] [P?] Description`
- **[P]** indicates the subtask can proceed in parallel (different files/components).
- Include precise file paths or modules.

## Path Conventions
- **Package root**: `packages/design-system/`
- **Source**: `packages/design-system/src/`
- **Tests**: Co-located with components (`*.test.tsx`)
- **Stories**: Co-located with components (`*.stories.tsx`)
