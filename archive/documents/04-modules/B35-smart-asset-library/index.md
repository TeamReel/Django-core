# B35 Smart Asset Library

**Status:** Beta
**Maintained by:** TeamReel Core

The Smart Asset Library provides centralized management for digital assets (images, videos, documents) with project-level scoping, smart metadata extraction, and polymorphic associations.

## Documentation

- [Extension Guide](extension-guide.md): How to integrate media with other modules.
- [API Reference](../../../src/medialib/README.md): Detailed API usage (module readme).

## Key Capabilities

1. **Asset Lifecycle**: Upload, process, generic, delete.
2. **Tagging**: System and Project scoped tags.
3. **Relation Engine**: Link assets to Matches, Players, Drills, etc.
4. **Collections**: Curate lists of assets.
