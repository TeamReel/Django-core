# Development Workflow

## Overview

Processes for building, testing, and deploying. We follow **Spec-Driven Development** with the Spec Kitty workflow.

## Key Workflows

*   **[Development Setup](development-setup.md)**: Local environment setup and quickstart.
*   **[Spec Kitty Workflow](spec-kitty.md)**: Feature lifecycle (Spec → Plan → Build → Review → Verify).
*   **[Git Workflow](git-workflow.md)**: Commit conventions and workflow.
*   **[Testing Strategy](testing.md)**: How to run and write tests (pytest, Playwright).
*   **[CI/CD & Deployment](cicd.md)**: Verification commands and Railway/Vercel deployment.
*   **[Railway Setup](railway-setup.md)**: Production deployment configuration.
*   **[Railway Staging Setup](railway-staging-setup.md)**: Staging environment.
*   **[Database Queries](database-queries.md)**: Common query patterns and optimization.
*   **[Extending Core](extending-core.md)**: Guide for building products on top of the core.
*   **[Post-Merge Cleanup](post-merge-cleanup.md)**: Steps after merging features.

## Quick Start

1.  **[Set up your environment](development-setup.md)**
2.  **Pick a task**: Check the [Roadmap](../02-roadmap/index.md) or `quick/todo/`
3.  **Follow Spec Kitty**: Spec → Build → Test → Verify
4.  **Commit**: Conventional commits, push to `main`
