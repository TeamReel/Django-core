# 🧱 Lokale Ontwikkelomgeving – TeamReel

## Backend
1. `python -m venv venv`
2. `.\venv\Scripts\activate`
3. `pip install -r backend/requirements.txt`
4. `python manage.py runserver`

## Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`

## Environment
Gebruik `.env.example` als basis voor `.env`
